# Замер скорости интернета

Делает 10 последовательных запросов к указанному URL, считает среднее время запроса, объём скачанных данных и скорость.

Нужен только Python 3 (без зависимостей).

## Запуск

```bash
python3 speedtest.py <url>
```

Пример:

```bash
python3 speedtest.py https://proof.ovh.net/files/10Mb.dat
```

Вывод:

```
 1: 10.49 MB за 0.77 с
...
10: 10.49 MB за 1.01 с
Среднее время запроса: 0.82 с
Скачано всего: 104.86 MB
Скорость: 12.75 MB/s (102.03 Mbit/s)
```
